Fix `SolverCoupledADMM` results that depended on how many worlds a model holds. Rigid-particle and particle-particle contact candidates now pair only entities from compatible worlds, the same rule the collision kernels apply, so entries whose solver cannot refresh inertial properties, such as `SolverMuJoCo`, no longer receive a static proximal mass summed over the candidates of every world, and the per-pair contact buffers no longer grow quadratically with the world count. Single-world results are unchanged; re-test multi-world baselines.
